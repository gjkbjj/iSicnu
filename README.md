# iSicnu

一站式四川师范大学服务平台，包名 `com.gakiji.isicnu`，支持 Android 12 及以上系统。

## 下载与更新

从 [Releases](https://github.com/gjkbjj/iSicnu/releases/latest) 下载最新的 `iSicnu-版本号.apk`。

App 支持自动检测更新，也可以在个人中心点击“检查更新”。从 0.24.0 起，检测到有效正式更新后必须更新，不提供关闭或跳过。同签名版本可覆盖安装并保留本机账号和缓存。

## 当前版本：0.25.0

- 普通 Android 桌面组件统一为固定 4×2；趣智新增唯一 2×2 热水表单按钮，控制已保存设备，点击开启、再次点击停止。
- 趣智改为底部液态玻璃悬浮导航，使用码移入账号，设备选择集中到紧凑面板。
- 多卡通未支付时，补充通过趣智校园官方 App 绑定免密支付的指引。
- App 内首页卡片尺寸保持不变，继续执行强制更新规则。

[完整版本说明](docs/releases/v0.25.0.md)。

## 更新日志

每个 Release 都包含本次更新说明、安装包和 SHA-256 校验值。

项目持续开发中，校园服务可用性取决于学校账号权限和网络环境。所有功能使用真实数据；校园会话及缓存按账号在设备本地加密保存。
