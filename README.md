# iSicnu

一站式四川师范大学服务平台，包名 `com.gakiji.isicnu`，支持 Android 12 及以上系统。

## 下载与更新

从 [Releases](https://github.com/gjkbjj/iSicnu/releases/latest) 下载最新的 `iSicnu-版本号.apk`。

查看 [1.1 更新说明](docs/releases/v1.1.0.md)。

App 支持自动检测更新，也可以在个人中心点击“检查更新”。从 0.24.0 起，检测到有效正式更新后必须更新，不提供关闭或跳过。同签名版本可覆盖安装并保留本机账号和缓存。

## 教务密码与课表安全

- **密码的去向**：教务密码只通过学校的 HTTPS 统一认证服务用于登录。iSicnu 不把教务密码发给项目服务器或 GitHub。
- **密码的保存**：只有你主动开启「快速登录 · Beta」，才会在本机保存教务密码。密码用 Android Keystore 管理的 AES-256 密钥加密，写入 App 私有目录。关闭快速登录或退出账号可以删除保存的密码。
- **课表的来源**：App 使用校方登录会话直接读取本科或研究生课表，本机缓存按账号隔离并加密。

[查看登录、密码存储与课表读取源码节选](docs/source-review.md)。

## iSicnu 1.0 公测

欢迎使用 iSicnu，

这是 iSicnu 的首个公测版。登录川师账号，就能在手机上查看课表、找空教室，处理常用校园事务。

- **课表与学业**：查看上课时间、教室、成绩和考试安排。
- **空闲教室**：按校区、日期和时段找自习教室。
- **图书馆**：查看座位预约和借阅信息。
- **校园一卡通**：查看余额和消费记录，打开校园付款码。
- **校园通知**：查看学校公告和狮谷热榜。
- **AI 助手**：配置 DeepSeek API Key 后，可用自然语言查课表、找空教室和整理日程。
