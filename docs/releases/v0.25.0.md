# iSicnu 0.25.0

- **桌面组件统一 4×2**：课程、热榜、成绩、二课、通知、教务、一卡通、考试、图书馆和取件码均只提供一个固定 4×2 入口，雨课堂动态组件继续 4×2。删除旧普通 2×2、4×4 注册与尺寸切换；App 内首页卡片的规格与排列保留。已有被移除尺寸的桌面组件需重新添加。
- **趣智热水表 2×2 按钮**：先在趣智校园登录并选用保存设备，再点击设备卡片的「添加桌面开关」或从系统小组件列表添加。整个组件只有一个操作，点击开启热水，再次点击停止；已保存设备为各实例共用，操作时显示进度并阻止重复点击，所有实例同步状态。未登录或未保存设备时点击进入趣智校园。
- 小组件复用 App 内的云控启停、加密缓存及订单归属校验；按当前校园账号隔离，旧账号、旧设备或旧订单的点击不会操作新目标。只有服务端确认结束才恢复开启按钮；未知结果保留并提示核对，不自动重开水。已知强制更新阻止新开水，停止用水仍可使用。
- **多卡通提示**：收到「多卡通未支付」时，说明需下载趣智校园官方 App，绑定免密支付后再返回开启设备；绑定后可卸载官方 App。保留服务器原始错误，不将普通网络失败解释为支付配置问题。
- 修正服务器明确拒绝开水后仍保留开启待确认记录的问题；明确拒绝后恢复可重试，网络结果不确定继续保留待确认记录。
- **趣智界面重整**：设备、账单、账号使用底部液态玻璃悬浮导航，使用码合并到账号页，仍保留预览、换码、确认领取及开关。设备区突出当前设备与启停，更换面板横向排列扫码、附近、输入，已保存设备集中展示，手动输入框按需展开。

包名 `com.gakiji.isicnu`，versionCode 53，最低 Android 12（API 31）。沿用上一正式版签名，可覆盖安装保留账号和缓存。继续执行 0.24.0 起的强制更新规则。

限制：热水表按钮支持已接入的云控设备，BLE 水表直连仍需官方客户端。设备控制需要网络和有效趣智会话；系统强行停止、省电限制及服务时限可能影响后台监控，未确认关停时需核对实际设备。当前无 ADB 在线设备或已配置模拟器，尚未完成真实桌面视觉、真实账号及实际开关阀验收。
