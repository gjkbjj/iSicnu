# iSicnu 0.24.0

- 校园生活加入「取件码」，仅保留淘宝。使用官方网页登录，展示真实身份码和待取包裹；刷新与添加手机号按钮采用玻璃胶囊样式。认证或内容整理失败时自动返回官方页面处理，不采集账号密码、不持久化码值。
- 取件码首页卡片和 Android 桌面组件只提供一个固定 **2×2 快捷入口**，点击进入功能页，不展示虚构包裹数量或缓存身份码。首页旧淘宝卡片自动迁移为 2×2，保留已有淘宝 2×2 桌面组件的注册身份；原拼多多及 4×2、4×4 取件桌面组件移除，需在桌面删除旧组件。
- 移除拼多多取件页面、登录适配、脚本、入口和组件注册。首次进入本版取件码时清理原取件浏览器会话，需要重新登录淘宝；不会清理教务或雨课堂会话。
- 校园生活加入「趣智校园」，设备、使用码、账单和账号使用液态玻璃页签与按钮。支持手机号短信／密码登录，按校园账号隔离并加密保存趣智会话与缓存。
- 趣智使用码支持查看、开关、候选码预览、换一个、确认领取和取消；只有确认领取才替换当前码，保留前导零，候选有效期和额度按服务端结果处理。
- 趣智钱包使用真实余额，提供月账单与详情；移除无效的校园卡支付余额请求，不做余额估算。顶部红色信息条改为必要的操作弹窗。
- 趣智增加相机扫码和补光，扫码后自动读取设备；空输入时点击「读取设备」直接扫码。蓝牙发现、输入 MAC 与设备原文仍可使用。读取时显示进度，成功显示设备名，失败明确反馈；后台资料刷新不再锁住读取按钮。
- 趣智支持云控设备开始／结束前确认、订单所有权检查、待确认状态持久化及后台状态通知。没有服务器关闭证据时不会报告结束，不操作他人订单；蓝牙直连水表会提示使用官方客户端。
- **从本版起强制更新**：检测到带有效主应用 APK 的正式新版本后，更新弹窗不接受返回键、点外部关闭，不提供稍后或跳过。打开下载链接或下载失败不会解除限制；已检测的更新要求会保存并在重启时恢复，安装对应或更新版本后解除。覆盖主界面、登录流程、取件浏览器、雨课堂及扫码界面。未检测到有效更新时，离线检查失败不额外阻止使用；不能追溯改变已安装旧版本的更新行为。
- 雨课堂移除右上角「登录说明」，说明仅首次进入功能时弹窗提示。

包名 `com.gakiji.isicnu`，versionCode 52，最低 Android 12（API 31）。沿用上一正式版本的既有签名，可覆盖安装保留数据。安装与下载仍由系统及浏览器完成，不静默安装、不拦截系统 Home 键。
