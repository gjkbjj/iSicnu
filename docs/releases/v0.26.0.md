# iSicnu 0.26.0

- **上课静音**：个人中心 → 课程新增开关。按当前课表在开课时自动静音、下课后恢复原来的铃声模式，连堂课保持到最后一节下课。开启需要「修改系统设置」授权，Android 7 起还需要勿扰访问；未授权时开关保持关闭或退回振动，不使用超过 7 天的课表执行。课表缺失、认证失效、课程缺少下课时间时一律不静音，并恢复之前的铃声。
- **三个快捷通道**：付款码、取件码、热水同时提供长按图标的静态快捷方式、个人中心「桌面快捷方式」固定的桌面图标，以及控制中心磁贴。三条通道只做跳转，不绕过登录与账号隔离；桌面不支持时明确提示，不伪造成功。
- **一卡通付款码**：首页一卡通卡片与一卡通页余额卡片右上角各有一个二维码按钮，底部弹层用当前会话打开校方付款码页面。只允许停留在学校一卡通主机，遇到登录跳转说明会话失效并给出重试，不解析、不缓存、不保存付款码内容。
- **2×2 今日课程组件**：新增固定 2×2 版课表组件，最多展示三行「开始时间 + 课程名」，优先未结束的课程，全部结束后回落到当天课程；无课、未同步、需认证、缓存过期分别显示状态，不使用占位课程。
- **2×2 热水组件重做**：改为热水器面板加圆形按钮，空闲为绿色播放三角、使用中为绿色实心暂停，处理中在圆钮内显示进度；状态行固定缩略为「热水表」，不再显示过长的设备名。
- **液态玻璃下沉**：所有功能页右上角刷新、完整课表的学期选择、周次切换、日期选择与课程卡片统一改为玻璃控件。
- **文案与趣智细节**：清理个人中心课程日历、图书馆、打印、趣智等等说明性文字；趣智设备页移除「添加桌面开关」，更换按钮改为玻璃加号；账单省略「热水表」重复前缀并移除账单详情；账号页隐藏姓名与更新时间；使用码减少解释文字。

包名 `com.gakiji.isicnu`，versionCode 54，最低 Android 12（API 31）。沿用历史版本一致的 Android Debug 签名，可覆盖安装并保留账号与缓存。继续执行 0.24.0 起的强制更新规则。

限制：控制中心磁贴与桌面快捷方式需要桌面或系统支持，部分定制系统会隐藏或延迟显示；三者都只负责打开功能页，不保存任何业务数据。上课静音依赖课表缓存与 AlarmManager，系统强行停止、厂商省电策略、未授予修改系统设置或勿扰访问时不生效。付款码页面由学校提供，页面结构变化时可能无法显示，App 内只做本机 WebView 展示。本次仍无 ADB 在线设备，快捷方式、磁贴与静音未在真机验收。
