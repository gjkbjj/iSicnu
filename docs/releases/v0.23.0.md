# iSicnu 0.23.0

- 个人中心新增“课程”设置分组，集中放置课程日历同步与课前实时活动。
- 打开课程日历同步时申请系统日历读写权限；授权后创建按校园账号隔离的 iSicnu 专属本地课程日历。日程标题为课程名，位置为“教室@老师姓名”，使用上海时区及真实课程起止时间、教学周。
- 课程拉取并保存当前学期缓存成功后自动核对日历；教室、教师、时间变化更新日程，调课和撤课移除旧日程并补入新安排，重复刷新不重复添加。浏览历史学期不覆盖当前日历。
- 未同步、认证失败、拉取失败及缓存过期分别反馈；课表缺少学期日期或有效课程时间时保留已有日历。关闭同步、退出或切换账号时仅清理本应用创建的课程日历；权限被撤销时暂停写入及清理，重新授权后可继续维护。
- 图书馆预约页按参考布局调整：顶部“自习座位 / 学习空间”、底部悬浮“预约 / 我的”均使用液态玻璃背景采样、磨砂及折射，沿用滑动、按压和回弹。已解锁的自动预约保留在底栏中。
- 校区卡片展示区域摘要、区域数量及真实汇总空座数；数据不完整时显示“—”，不填充示意图数值。区域、选座、预约记录及信用查询沿用现有真实接口。
- 设置开关保留玻璃折射并增强透明度，移除开关、设置项及设置内 Material 按钮的原生按压波纹；玻璃控件本身的高光与材质阴影保留。

包名 `com.gakiji.isicnu`，versionCode 51，最低 Android 12（API 31），沿用 v0.22.0 的既有签名，可覆盖安装保留数据。日历由应用在课程同步成功后维护，后台刷新时效受 Android 调度与校方网络限制；系统日历中的课程内容由系统日历提供程序保存，应用内课程缓存仍按账号加密。

验证：217 项单元测试全部通过，Release 构建与 lintRelease 通过，16 KB 对齐及签名校验通过，签名证书与既有正式发布一致。覆盖课程周次展开、重复数据、调课、教室/教师/时间变化、空课表、缺失日期及校区空座汇总。当前 ADB 无设备连接，未完成真机日历提供程序写入、系统授权弹窗及液态玻璃视觉复测；未提交真实图书馆预约。
